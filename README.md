# Toolshop API Tests

Учебный проект по API-тестированию сервиса Toolshop в Postman.

В ходе тестирования самостоятельно нашел и задокументировал воспроизводимый критический баг: данные корзины доступны без заголовка `Authorization`.

## Протестировал

* Регистрация и авторизация пользователя
* Создание корзины
* Получение списка товаров
* Добавление товара в корзину
* Получение корзины и проверка добавленного товара
* Удаление товара из корзины
* Проверка пустой корзины после удаления
* Негативные проверки

## Связанный сценарий

Папка в коллекции Postman `Linked scenario — cart workflow` проверяет полный путь пользователя:

1. Регистрация
2. Авторизация
3. Создание корзины
4. Получение товаров
5. Добавление товара в корзину
6. Проверка корзины
7. Удаление товара
8. Проверка пустой корзины

Сценарий успешно запущен в Collection Runner в двух итерациях.

## Найденный баг

**BUG-01 — Доступ к данным корзины без авторизации**

Запрос `GET /carts/{cart_id}` без заголовка `Authorization` возвращает `200 OK` и данные корзины.

Ожидаемый результат — `401 Unauthorized`.

Подробнее: `docs/bug-report.md`

## Environment

Файл `environments` содержит environment для запуска коллекции.

Статические переменные:

* `base_url` — базовый адрес API
* `invalid_access_token` — невалидный токен для негативного теста

Динамические переменные заполняются автоматически во время выполнения сценария:

* `registered_email`
* `access_token`
* `user_id`
* `cart_id`
* `product_id`
