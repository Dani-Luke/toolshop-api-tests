# Toolshop API — Баг-репорты

## BUG-01 — Доступ к данным корзины без авторизации

**Заголовок:**
Данные корзины доступны без заголовка Authorization

**Окружение:**

* Приложение: Toolshop API
* Postman Collection: `Toolshop API Tests`
* Запрос: `GET cart by id — no token`
* Переменная окружения: `Toolshop Dev`

**Серьёзность:** Высокая

**Приоритет:** Высокий

**Тип:** Функциональный дефект / дефект безопасности

**Предусловия:**

* Пользователь зарегистрирован и авторизован.
* Создана корзина.
* Известен `cart_id` созданной корзины.

**Тестовые данные:**

* Cart ID: `{{cart_id}}`
* Authorization: заголовок отсутствует

**Шаги воспроизведения:**

1. Создать корзину от имени авторизованного пользователя.
2. Сохранить `cart_id` созданной корзины.
3. Отправить запрос без заголовка `Authorization`:

```http
GET {{base_url}}/carts/{{cart_id}}
```

4. Проверить статус-код и тело ответа.

**Фактический результат:**
API возвращает `200 OK` и данные корзины. В ответе присутствуют идентификатор корзины `id` и массив товаров `cart_items`.

**Ожидаемый результат:**
API возвращает `401 Unauthorized`, поскольку запрос не содержит заголовка `Authorization`. Данные корзины не должны быть доступны без действующего Bearer Token.
