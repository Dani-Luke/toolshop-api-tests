# Чек-лист тестирования Toolshop API

## Регистрация пользователя

- Успешная регистрация пользователя с валидными данными
- Email генерируется динамически через `{{$randomUUID}}`
- Email сохраняется в переменную `registered_email` перед отправкой запроса
- Email из ответа API совпадает с email, который был отправлен
- В ответе содержатся данные созданного пользователя
- Регистрация с уже существующим email возвращает `409`
- Регистрация без обязательного поля возвращает `400`
- Регистрация с некорректным форматом email возвращает `400`

## Авторизация пользователя

- Корректный логин зарегистрированного пользователя
- После логина возвращается `access_token`
- `access_token` сохраняется в environment
- `user_id` сохраняется в environment
- Логин с неверным паролем возвращает ошибку авторизации
- Логин с несуществующим email возвращает ошибку авторизации
- Логин без обязательных полей возвращает `400`

## Создание корзины

- Успешное создание корзины авторизованным пользователем
- В ответе возвращается `cart_id`
- `cart_id` сохраняется в environment
- Создание корзины без токена возвращает `401`
- Создание корзины с невалидным токеном возвращает `401`

## Получение товаров

- Получение списка товаров возвращает `200`
- В ответе содержится массив товаров
- У товаров есть идентификатор `id`
- `product_id` первого товара сохраняется в environment
- Получение несуществующего товара возвращает `404`

## Добавление товара в корзину

- Успешное добавление валидного товара в корзину
- В запросе используется `cart_id` из environment
- В запросе используется `product_id` из environment
- В запросе передаётся корректное значение `quantity`
- В запросе используется Bearer Token из environment
- После добавления товар отображается в `cart_items`
- Количество товара соответствует заявленому числу
- Добавление товара с `quantity: 0` возвращает ошибку валидации
- Добавление товара с отрицательным количеством возвращает ошибку валидации
- Добавление несуществующего товара возвращает `404`
- Добавление товара без токена возвращает `401`
- Добавление товара с невалидным токеном возвращает `401`

## Получение корзины

- Получение корзины по `cart_id` возвращает `200`
- В ответе присутствует массив `cart_items`
- Добавленный товар отображается в `cart_items`
- Количество добавленного товара соответствует заявленому числу
- Получение несуществующей корзины возвращает `404`
- Получение корзины без токена возвращает `401`
- Получение корзины с невалидным токеном возвращает `401`

## Удаление товара из корзины

- Успешное удаление добавленного товара из корзины
- Запрос удаления возвращает `204`
- После удаления выполняется повторное получение корзины
- Удалённый товар отсутствует в `cart_items`
- После удаления массив `cart_items` пустой
- Удаление товара из несуществующей корзины возвращает `404`
- Удаление товара без токена возвращает `401`
- Удаление товара с невалидным токеном возвращает `401`

## Связанный сценарий

- Регистрация выполняется с уникальным email
- Логин выполняется после регистрации
- `access_token` передаётся в последующие запросы
- `cart_id` передаётся из создания корзины в запросы корзины
- `product_id` передаётся из списка товаров в добавление товара
- После удаления товара корзина становится пустой
- Связанный сценарий запускается через Collection Runner
- Сценарий успешно проходит в первой итерации
- Сценарий успешно проходит во второй итерации
